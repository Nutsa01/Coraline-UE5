# Coraline-inspired game - Unreal Engine 5

<h3 align="center"><a href="README.md">Français</a> · <b>English</b></h3>

A 3D exploration game inspired by Coraline, made with Unreal Engine 5 and mainly programmed in Blueprints. The player explores a house, interacts with objects and characters, cooks recipes and meets a monster that can chase them.

## Features

- Exploration of the real house and the other house
- Interactions with doors, keys, mirrors and objects
- Dialogue with the characters, with their portrait on screen
- Cooking interface: choosing ingredients, recipes and oven settings
- A monster that patrols, chases the player and attacks
- Main menu, saved options and controls screen
- Different music and ambient sounds for each house

**Tools used:** Unreal Engine 5.7, Blueprints and UMG.

## Run the project

Clone the repository with Git LFS installed, then open `CarolineJeu.uproject` with Unreal Engine 5.7.
